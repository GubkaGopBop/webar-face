# Практическая работа 3 — MindAR Face Tracking

WebAR-фильтр с симметричными 3D-очками. Маркер не нужен: MindAR распознаёт лицо, привязывает очки к переносице (landmark 168) и обновляет их положение, поворот и масштаб.

## Файлы

- `index.html` — страница WebAR и карта импортов;
- `app.js` — камера, якорь, сглаживание, окклюдер и настройки;
- `glasses.js` — собственная 3D-модель из геометрии Three.js;
- `styles.css` — интерфейс для компьютера и телефона;
- `preview.html` — просмотр той же модели без камеры;
- `.nojekyll` — отключение Jekyll при публикации.

MindAR 1.2.5 и Three.js 0.151.3 загружаются с jsDelivr. Версии закреплены: эта сборка MindAR импортирует `sRGBEncoding`, который доступен в выбранной версии Three.js. Интернет нужен также для загрузки модели распознавания MediaPipe.

## Запуск

Из папки `Пр3`:

```powershell
python -m http.server 8000
```

Откройте `http://localhost:8000`, нажмите «Включить камеру» и разрешите доступ. На телефоне используйте HTTPS-ссылку GitHub Pages. Открытие через `file://` или обычный HTTP по IP компьютера не подходит для камеры.

## Привязка и устойчивость

- Якорь `addAnchor(168)` расположен на переносице.
- Начальный масштаб: `1`; позиция относительно якоря: `(0, 0.06, 0.08)`.
- Размер, высота и отступ регулируются в панели «Подогнать очки».
- Все детали объединены в одну группу: очки сохраняют симметрию и следуют общей позе лица.
- Встроенный One Euro Filter: `filterMinCF: 0.001`, `filterBeta: 1`; фильтруются ключевые точки, матрица лица и масштаб. Это базовая настройка для проверки, а не гарантия устойчивости на любом устройстве.
- Окклюдер лица скрывает дужки за лицом при повороте головы.
- Плотность рендера ограничена значением `1.5` для снижения нагрузки.
- При потере лица MindAR скрывает фильтр. Кнопка остановки освобождает камеру; уход со страницы также останавливает её.
- Видео обрабатывается локально; приложение не записывает и не отправляет кадры.

## GitHub Pages

1. Создайте публичный репозиторий `webar-face-pr3`.
2. Загрузите **содержимое** папки `Пр3` в корень: `index.html` должен находиться в корне репозитория.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку `main`, папку **/(root)**, нажмите **Save**.
5. Дождитесь завершения публикации и откройте ссылку **Visit site**. Обычно она имеет вид `https://ИМЯ.github.io/webar-face-pr3/`.
6. Проверьте сайт на телефоне и компьютере. Отчёт хранится отдельно, загружать его для работы сайта не нужно.

Если репозиторий содержит папку `Пр3` вместо её содержимого, ссылка на сцену заканчивается `/Пр3/`; для простоты рекомендуется отдельный репозиторий с файлами в корне.

## Проверка перед защитой

При ровном освещении держите лицо в кадре, затем плавно поворачивайте голову влево и вправо примерно на 20–30°, наклоняйте её и меняйте расстояние до камеры. Очки должны оставаться у глаз, дужки — уходить за лицо. Уберите лицо из кадра: фильтр должен исчезнуть. Вернитесь в кадр: фильтр должен появиться снова. Проверьте остановку и повторный запуск камеры. Повторите на телефоне.

При дрожании можно уменьшить `filterMinCF`; при заметном отставании — увеличить `filterBeta`. Изменения требуют повторной проверки: усиление сглаживания может добавить задержку. Резкие повороты, слабый свет и перекрытие лица ухудшают распознавание.

## Коротко для защиты

«Камера передаёт кадры MindAR. MediaPipe находит ключевые точки лица. К точке 168 на переносице прикреплена группа 3D-очков. MindAR обновляет её позу и масштаб, а One Euro Filter уменьшает дрожание. Геометрия лица используется как окклюдер: она невидима, но скрывает детали за лицом. GitHub Pages даёт HTTPS, необходимый для камеры на телефоне».
